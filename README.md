# Hi, I'm Jorge Moutinho

I'm a PhD student in Environmental and Molecular Biology at the University of Minho. 
My work focuses on (e)DNA (meta)barcoding for marine biodiversity, using genetic data to understand and monitor life in aquatic ecosystems. 
Currently, my work focuses more on the bioinformatic side of DNA metabarcoding data, and I'm learning computational tools to better handle and analyse this kind of data.
